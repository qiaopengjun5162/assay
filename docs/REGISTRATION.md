## 项目简介（100~200 字，可直接粘贴）

```
浙江省公共数据开放平台有 24,322 个数据集，官方只公布数量指标，没有数据集级质量评价。数验 Assay 对全部数据集做确定性体检，回答三件事：字段清单写的是不是真的（有一份声明 7 列、实际 92 列）、还有没有人在维护（56.2% 超 90 天没更新）、空值是「没有」还是「没填」（16.3% 整列全空）。

和一般数据质量工具只出报告不同，我们把每条结论变成可验对象：接口原始响应 + SHA-256 钉住时点 + Lean 4 定理交给内核重验计数。报告被转发十次，别人不信任发布者也能自己复核。模型刻意做窄——不取数、不算数，只写解释且过数字护栏。交付的是一把可复用的尺子：同一套内核换一份完全不同形状的数据，core 一行不改照样检出问题。
```

## 自查命令（若报名表要填"如何复现"）

```
just check     # 格式 / clippy 零容忍 / nextest / 依赖审计 / 证明门禁
just smoke     # 200 条端到端
just tamper    # 改一位数字，Lean 内核当场拒绝
just verify-live  # 验线上活站是不是仓库冻结版、证据能否重算
```

## 边界（若报名表问"局限/不声称什么"）

```
不评价准确性（没有权威源，硬评就是编）；样例级体检（表头 + 5 行，不是全量明细）；
不证明平台数据本身为真（证明对象是「从快照推出的计数」）；
第二个真实平台尚未接入（卡在数据授权，不是代码；抽象已用第二份数据实证）。
```
